# 洛雪音源 · JSplitter 面板 v2.0.1

在 foobar2000 的 **foo_uie_jsplitter** 面板里跑洛雪（LX Music）音源：拉各平台排行榜、搜索、
歌单 / 播客 / 歌手，看歌曲评论与艺人介绍，把取到的直链**下载到本地、写标签、把封面嵌进音频文件**
之后再送进 foobar2000 播放 —— 所以 foobar2000 自带的 Album Art 和各种封面面板都能直接显示。
支持平台：**QQ 音乐 / 网易云 / 酷我 / 酷狗 / 咪咕**。
断网也能重播，标签、封面、歌词全在文件里，播放列表里看到的就是整理好的曲目信息。

## 一、界面

整块面板自上而下三段：**顶栏（62px）· 内容区 · 底栏（24px）**，区块之间不留缝隙，
靠 1px 分隔线和底色差区分。

### 顶栏

| 位置 | 内容 |
| --- | --- |
| 左上（第一行） | LXbox 标志（`lxbox-logo.png`，52×26；图丢了退回「网络音乐」四个字） |
| 左上（第二行） | **Lxbox v2.0.1** —— 面板版本号（窄面板只显示 `v2.0.1`）。导入音源已挪到「设置 → 维护」 |
| 中间（第一行） | 五个页签：**排行榜 · 搜索 · 歌单 · 播客 · 歌手** |
| 中间（第二行） | 平台：**腾讯 · 网易 · 酷我 · 酷狗 · 咪咕**（与上方页签同列对齐） |
| 右上（第一行） | **人物按钮**（= 艺人介绍）+ **音源：自动 ▾** 下拉框（面板宽 ≥ 600 时显示）；音源格从人物按钮右边一直撑到面板右边缘 |
| 右上（第二行） | **气泡按钮**（= 歌曲评论）· **音质 320K ▾** · **设置**；最右的「设置」永远常驻，变窄时依次收起「音质 → 气泡 / 人物」 |

页签和平台都是两行同列：点「排行榜」下面那一列就是「腾讯」，一眼能看出当前是哪套组合。

右上那块是**两行三列**，上下严格对齐：

```
  第一行   ( 人物 ) │ 音源：自动 …………………………▾
  第二行   ( 气泡 ) │ 音质 320K ▾ │ 设置
           └─ 列 1 ─┘└─ 列 2 ───┘└ 列 3 ┘
```

- 列 1 是两个**纯图标按钮**：上面是「人」的剪影 = 艺人介绍，下面是对话气泡 = 歌曲评论。
  换成图标之后这一列从 68px 收到 30px，右半边一下就松了，不再和页签挤在一起。
  图标只用 `FillSolidRect` 逐行堆出来（不赌宿主 gdi 有没有 `FillEllipse`），
  颜色跟原来的文字一致：平时是正文色，指上去转青色
- 列 1：两个图标按钮同 x 同宽，上下正对
- 列 2：音源 / 音质 左端同一点；音源那格更长，向右吃掉「设置」上方的空白
- 列 3：只有第二行有「设置」，右端 = 面板右边距，最后才被挤掉
- 面板变窄的顺序：音质（< 440）→ 音源（< 600 或放不下 88px）→ 气泡 / 人物（压到页签上时）

### 左栏

左侧是「榜单」或「集合」列表（宽 190px），贴面板左边，行高 27px，选中行左侧一条竖线。

**右上角有一个 18×18 的箭头按钮，可以把左栏收起来：**

| 状态 | 左栏宽度 | 箭头 | 左栏内容 |
| --- | --- | --- | --- |
| 展开 | 190px | 朝左（点它收起） | 完整列表 |
| 收起 | 26px | 朝右（点它展开） | 一条窄边：箭头 + 竖排的「榜单 / 歌单 / 播客 / 歌手」 |

- 收起后**右侧曲目区整宽显示**，标题、曲目行、滚动条一起往左让位；面板够宽时还能顺势从单列变两列
- 收起状态记在属性 `lx.sideCollapsed`，下次打开还是上次的样子
- 收起时左栏不参与命中：点击、滚轮、右键都不会落到列表行上，左栏的滚动条也一起撤掉
- 歌单 / 播客 / 歌手页原有的「推荐 / 刷新」按钮左移 22px 给箭头让位，两者不重叠

### 曲目区

- 行高 44px（双行：第一行歌名，第二行「歌手 · 专辑 · 时长」），可在设置里切成**单行**（行高 30px）
- 行首一个方框用于**多选**，行尾「播放 / 队列」两个按钮
- 内容宽 ≥ 620px 时自动排**两列**（第 1、2 首并排，第 3、4 首下一行），窄回去自动单列
- 右侧一条细滚动条：可以按住拖，也可以点空白处直接跳

### 底栏

左边是最近一次操作的状态文字（失败时变红），右边是提示「音源 5 · 双击播放」或「已勾选 N 首」。
**点一下底栏**打开诊断 / 日志浮层 —— 取链失败、封面没嵌进去时，原因都写在那里。

## 二、五个页签

| 页签 | 内容来源 | 说明 |
| --- | --- | --- |
| **排行榜** | 各平台榜单接口 | 左栏选榜单，右侧出前 100 首 |
| **搜索** | 各平台搜索接口 | 不输关键词时直接显示**热门推荐**（当前平台的热歌 / 新歌 / 飙升榜，60 首） |
| **歌单** | 网易云个性化推荐 / QQ 热门歌单 / 酷我 · 酷狗 · 咪咕歌单搜索 | 进去就有内容，不用先输关键词 |
| **播客** | 网易云主播电台榜 | 目前只有网易云有播客，切到其它平台会直接提示 |
| **歌手** | 网易云歌手榜 / QQ 歌手列表 / 酷我 · 酷狗 · 咪咕热歌榜上的歌手 | 取 60 位，点进去是该歌手的热门歌曲 |

几个要点：

- **推荐跟着平台走**：切平台，当前页的推荐立刻换成新平台的（缓存按「平台 + 类型」分开存）
- **搜索词不写进属性**：重开软件后搜索框是空的；同一会话内切页签回来仍记得刚输的词
- **推荐列表缓存 10 分钟**：来回切页签不会反复请求，左栏右上角的「推荐 / 刷新」按钮可强制重取
- 歌单 / 播客 / 歌手**点左侧条目**，右侧就出曲目；**双击**播放
- 这些入口全部走平台公开接口，**不依赖音源脚本** —— 某个音源脚本失效时照样能浏览，
  只有点播放时才受取链影响

### 搜索框怎么输

点搜索框（或按 `/`）直接在面板里打字，`回车` 搜索、`Esc` 取消、`Backspace` / `Delete` / `←` / `→` 编辑、
`Ctrl+V` 粘贴。

> 中文输入法的组词候选框在 SMP / JSplitter 面板里画不出来（没有 IME 控件），
> 中文关键词请用右键 **「输入关键词（中文输入法）…」** 走系统输入框，或先在别处打好再 `Ctrl+V`。
> 英文和数字可以直接在框里打。

## 四、歌曲评论

点顶栏第二行的**气泡按钮**（歌曲评论）或按 `F3`。对象永远是**当前正在播放的曲目**。

| 项 | 说明 |
| --- | --- |
| 数据源 | 网易云评论接口（热评 + 最新合并去重，最多 30 条） |
| 定位方式 | 面板点播的缓存文件靠写入的标签反查回平台曲目（能拿到歌曲 ID，评论更准）；放别处的本地文件按 `%title% + %artist%` 匹配同名曲 |
| 不串歌 | 歌名相同但歌手不同会当成两首 |
| 缓存 | `cache\review\歌手 - 歌名.json`，7 天 |
| 排版 | 正文宽 ≥ 700px（面板 ≥ 734px）时自动**两列**，一条评论不会被劈开；两列中间一条 1px 竖线 |
| 滚动 | 滚轮 / `↑` `↓` / `PgUp` `PgDn` / 拖滚动条，两列共用一个滚动位置 |
| 音源 | 与播放共用**顶栏右上角第一行**的「音源：…」下拉框（见第十节）；评论本身走内置网易云接口，换脚本不影响取评论 |
| 关闭 | 右上角 `×`、`Esc`、点浮层外面 |

评论浮层顶端**没有标题条**：标题与副标题（「歌手 · 歌曲 · 来源 · 缓存时间」）写在左列顶部两行，
`×` 单独浮在右上角。（诊断 / 日志浮层仍保留标题条，那里没有分栏，留一条标题才好认。）

## 五、艺人介绍

点顶栏第一行的**人物按钮**（艺人介绍）。查的是当前播放曲目的歌手。

### 三分区

```
┌──────────────────────────┬─────────────────────────┐
│  歌手图片（正方形 ≤600）  │   介绍正文（单独滚动） × │
├──────────────────────────┤                         │
│  热门歌曲 15 首 + 更多…   │                         │
└──────────────────────────┴─────────────────────────┘
```

| 项 | 说明 |
| --- | --- |
| 图片 | 上限 **600×600 正方形**；空间不够等比缩，按 cover 居中裁剪，不拉伸变形 |
| 左栏宽 | 约浮层宽的一半，但右侧正文至少留 260px |
| 热门歌曲 | 默认 **15 首**，每点一次「更多…」再加 15 首；本地这份用完会按歌手 ID 再拉一次列表（最多 50 首）合并 |
| 窄 / 矮面板 | 浮层宽 < 520px 或正文高 < 210px 时**退回通栏长文**，不硬挤成两个窄条 |
| 缓存 | 简介 `cache\bio\歌手.txt`（30 天）、图片 `cache\artist\歌手名.jpg`、热门歌曲 `cache\artist\歌手名.songs.json`（30 天） |

### 点哪里出什么

| 操作 | 结果 |
| --- | --- |
| 单击歌手图片 | 播放 / 暂停 |
| 双击歌手图片 | 用系统默认看图程序打开这张缓存下来的图片 |
| 单击热门歌曲行 | 选中（行首序号高亮，左边一条竖线） |
| 双击热门歌曲行 | 直接播放这一首 |
| 右键热门歌曲行 | 菜单：`播放：歌名` / `加入「播放列表」：歌名` |
| 滚轮 | 鼠标在左栏滚歌单，在右侧滚正文，两个滚动条各管一块 |
| 顶栏「音源：…」 | 与播放共用同一个选择（右上角第一行的音源下拉，见第十节）；艺人资料走内置接口，换脚本不影响取资料 |
| 关闭 | 右上角 `×`、`Esc`、点浮层外面 |

> 单击图片会先等 240ms 再动手：双击会撤掉这一次，免得「双击打开图片」顺带把歌暂停一下。
> 浮层里除了热门歌曲那一行，其余位置**不弹右键菜单**。

歌名拆分做了处理：`周杰伦、费玉清`、`陈奕迅 Eason Chan`、`A feat. B` 这类会拆开逐个匹配，
同名 / 别名命中里取作品最多的那位。

## 六、播放链路

### 流程

```
取链 → 下载到 cache\歌手 - 歌名.<ext>.part → 改名去掉 .part
     → 取歌词（9s 超时）+ 取封面（600 宽，落 cache\covers\）
     → 加入「洛雪音源」播放列表（此时拿到 metadb handle）
     → ① 文本标签：foobar2000 UpdateFileInfoFromJSON（重建整个 tag 块）
        ② 封面：读字节 → 塞进 APIC / PICTURE → 自检 → 写回（同步完成）
     → handle.RefreshStats() 让 fb2k 重读文件（封面一起生效）
     → 播放
```

顺序是「先进列表拿到 handle → 再写标签 → 刷新 → 播放」：标签一定先落盘，
播放时播放列表里显示的就已经是新信息。文件此时还没被 foobar2000 打开，写入不会被打断。

### 命名与去重

- 文件名就是 `歌手 - 歌名`，全部平铺在 `cache\` 里，例如 `cache\周杰伦 - 晴天.flac`
- 非法字符（`\ / : * ? " < > |`）、结尾空格与点、保留名（CON / PRN / …）会自动处理
- 同歌手同曲名的不同录音自动加 ` (2)`、` (3)`；换音质时扩展名不同，两条并存
- `cache\index.json` 记录「平台 + 曲目 ID + 音质 → 文件名」，再次播放直接命中本地文件，
  也会跳过重复写标签；条目指向的文件被删掉时自动作废

### 写标签

| 项 | 做法 |
| --- | --- |
| 文本字段 | 只写 TITLE / ARTIST / ALBUM / DATE / GENRE / LYRICS，用 foobar2000 自己的 tagger（mp3 / flac / m4a / wav / ogg 通吃） |
| 封面 | 内置 JS 写入器（`tagwriter.js`）：MP3 → ID3v2.3 `APIC`，FLAC → `PICTURE` |
| 自检 | 写入前在内存里自检，写完比长度，任何一步不对就放弃并保留原文件 —— 宁可不嵌也不写坏 |
| 音频数据 | 一个字节都不改（真机上用 ffmpeg 解成裸 PCM 比过 md5，完全一致） |
| 兜底 | 内置写入器不可用或格式不支持（m4a 等）时退回 `AttachImage`（异步，等 700ms 再刷新播放） |

`%date%` / `%genre%`：只有平台接口确实返回了才写，多数平台不提供 genre，通常为空 —— 这是数据源限制。

歌词写入 MP3 的 `USLT`（lang=chi）/ FLAC 的 `LYRICS`；foobar2000 没有 `%lyrics%` 字段，
读歌词需要 ESLyric 之类组件。

### 封面放在哪

- 默认**不写任何图片文件**：封面已经在音频文件里，平铺目录里再放一张 `cover.jpg` 会被后面的歌反复顶掉
- 老组件只认「音轨旁边的图」时，把 `lx.pushCover` 设 `1`，会给每首歌写一张**同名** `歌手 - 歌名.jpg`
- 面板自己的模糊背景用 `cache\covers\` 那份，互不影响

### 排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 控制台 `写标签失败（不影响播放）：未找到 tools\lx_tag.ps1` | `tools\lx_tag.ps1` 没放对位置，或 `lx.moduleDir` 指向了旧目录 |
| `foobar2000 写标签失败（…），改用内置写入器` | 当前 JSplitter 没有 `FbMetadbHandleList` / `AttachImage`；面板自动退回备用写入器，不影响播放 |
| `SKIP: unsupported .m4a` | 只有退回内置写入器时才会出现（它只认 mp3 / flac）；正常情况下 m4a 由 foobar2000 写 |
| `ERR: not a flac file` / `bad output size` | 文件不是标准 FLAC / MP3 或下载不完整，删掉该缓存文件重播 |
| foobar2000 里不显示封面（面板背景有） | 先看底栏诊断：「封面：嵌入音频文件」是否开着；再看那首歌是「已写入标签 + 内嵌封面」还是「封面未嵌入（原因）」。也可以右键曲目 → Properties → Artwork 确认 |
| 日志 `OK mp3 cover=0` | 这次没取到封面图（平台没图 / 网络不通） |
| 嵌完封面文件变大 | 正常：600×600 封面约 30~80 KB。想省空间换 320K，或把 `lx.embedCover` 设 `0` |
| `cache\` 里文件乱了想重来 | 设置 → 维护 → **清空缓存**（只删音频与 `index.json`，评论 / 资料缓存保留） |
| 路径含中文时写标签总失败 | 老版 PowerShell 5.1 对非 ASCII 参数支持不佳；把 `lx.cacheDir` 指到纯英文目录（如 `D:\fb2k-cache`） |
| PowerShell 被执行策略拦住 | 调用时已带 `-ExecutionPolicy Bypass`；若仍不行，说明组策略强制禁止脚本 |

- **字号默认跟随 foobar2000**：取自首选项 → 显示 → 字体里的「默认」那一项，fb2k 里改字体，

## 九、安装与升级

**环境**：foobar2000 + **foo_uie_jsplitter** 面板（SMP 系）。界面全部用 GDI 自绘，
不依赖 WebView、不需要任何第三方组件；封面嵌入用自带 JS 写入器，也不要求装额外插件。

   `[LX][ok] 已写入标签：…`；看到 `[LX][warn] 写标签失败…` 就查上面的排查表。

> 覆盖后在 Configure 里点一次 Apply（或重开面板），否则 JSplitter 可能还在跑缓存的旧脚本。

## 十、音源脚本放在哪

标准位置：**`C:\Program Files\foobar2000\profile\Lxbox\resources\`**

```
profile\Lxbox\
├─ main.js  crypto.js  tagwriter.js  lx.js  providers.js    ← 不用动
├─ lxbox-logo.png  tools\lx_tag.ps1
└─ resources\
    ├─ 五合一音源.js
    └─ 墨澜音乐源v2.3.4.js
```

查找顺序（找到第一个含 `.js` 的目录就用它）：

1. 属性 `lx.scriptDir` 指定的目录
2. `<模块目录>\resources`、`<模块目录>\sources`、`<模块目录>` 本身
3. `<组件目录>\net\sources\`、`<组件目录>\net\`
4. `<profile>\Lxbox\`
5. 兜底：在整个 `<profile>` 下按 `crypto.js` 通配扫描（目录被改名 / 搬走也能认）

目录里如果有 `音源列表.json` 就按清单加载，否则自动扫描 `*.js`；
`crypto.js`、`providers.js`、`lx.js`、`tagwriter.js`、`main.js` 会被自动排除。

新增音源：把洛雪音源 `.js` 丢进 `resources\` 重载面板即可；
也可以走 **设置 → 维护 → 导入音源…**，它会直接写进 `resources\` 并立刻重载。

### 给某个平台指定脚本

同一个平台（比如腾讯）可能有好几个脚本都声明支持，取链时默认按脚本加载顺序挨个试。
想固定用哪一个，就在**主界面右上角第一行**（人物按钮右边）点那个长条下拉框：

```
LXbox   排行榜   搜索   歌单   播客   歌手      (人物)  [音源：自动 …………………▾]
v2.0.1  腾讯    网易   酷我   酷狗   咪咕      (气泡)  [音质 320K ▾]  [设置]
                                             └ 列1 ┘└──── 列2 ────┘└ 列3 ┘
```

它下面那格是音质下拉（自动 / 128K / 320K / FLAC），两格左端对齐。

第二排那五个平台按钮（腾讯 / 网易 / 酷我 / 酷狗 / 咪咕）可以在
**设置 → 外观 → 第二排音源平台** 里整排隐藏。藏起来以后整条顶栏**收成一行**：

```
LXbox   排行榜   搜索   歌单   播客   歌手        (人物)(气泡)[设置]
```

版本号「v2.0.1」、音源下拉、音质下拉一起收起，气泡与设置挪到「人物」右边，
顶栏高度从 62 降到 40，下面的内容整体上移 22px。代价是这两样在顶栏上就点不到了：
换平台去 **设置 → 外观 → 数据来自**，改音质去 **设置 → 外观 → 音质**，
选音源脚本先把第二排显示回来。

排行榜、搜索、歌单、播客、歌手的数据统一按「数据来自」选的那家拉，默认网易云。
想临时换一家，把第二排显示出来点，或者回设置里改。
没隐藏时点平台按钮会写 `lx.platform`；隐藏时只动 `lx.fixedPlatform`，`lx.platform` 原样留着，
再把第二排显示回来就回到上次点的那个。

- 没指定时写「音源：自动」，指定后写脚本名（青色底 + 青字，一眼看出被改过）
- 换平台自动换成那个平台自己的选择：`lx.script.tx` / `lx.script.wy` 各存一份
- 面板窄于 600px 时这一格收起，把宽度让给平台按钮；点播照旧按加载顺序取链
- 评论 / 艺人介绍浮层开着时也能直接点它换脚本，换完浮层不会被关掉

菜单里：

- **自动（按脚本加载顺序）** —— 默认，面板自己挨个试
- 声明支持当前平台的脚本，前面打勾的就是当前选中
- 不支持当前平台的脚本灰掉，后面标明「（不支持网易）」之类
- 末尾两项：**重新加载音源脚本** / **打开音源脚本目录…**（走 `file://` URL 交给资源管理器；目录不存在或不给开会在状态栏写明路径，不再点了没反应）

选完立刻生效：写进属性 `lx.script.<平台>`，同时清掉取链缓存，下一次点播就用它。
指定**不是排他**的 —— 它排在最前面，取不到链时其余脚本照样顶上。

### 音源音质检测

脚本在 `inited` 里声明的 `qualitys` 只是「它想提供这几档」，实际能不能拿到直链要看平台
（VIP 专享、版权、下架、接口改版）。所以光看声明没用，得真去要一次。

入口：**设置 → 音源与属性 → 「音源音质检测…」**，打开一张 5 × 3 的表：

```
音源音质检测                                          12:31:05 检测 · 9/15 格可用（腾讯 3 档…）
──────────────────────────────────────────────────────────────────
音源      128K          320K          FLAC
腾讯      可用 0.6s     可用 0.8s     失败
网易      可用 0.9s     仅地址        失败
酷我      可用 1.1s     失败          失败
酷狗      可用 0.7s     失败          失败
咪咕      可用 1.4s     失败          失败

可用 = 拿到直链，且前 64 字节是音频文件头
仅地址 = 有链接，但内容不像音频 / 没能验证
失败 = 这一档没取到　　— = 脚本没声明这一档
[重新检测]  检测中：正在检测酷我 …（3/5）
```

**它是怎么测的**

1. 每个平台用同一个关键词（`爱`）搜 24 首当样本，每档最多试 **2 首**；两首都失败才判失败 ——
   单首失败常常只是这首歌没有这一档
2. 只问**这一档**：走 `NM.lx.probeUrl()`，每个脚本只请求一次、拿到就返回，**不降级**。
   播放用的 `resolve()` 会 flac→320k→128k 一路退，拿它来检测等于「有 128k 就算 FLAC 可用」，
   整张表会全绿
3. 腾讯优先用内置取链（`txUrlExact`，按单一文件名精确问 vkey），内置不行再交给脚本
4. 拿到地址后再 `Range: bytes=0-63` 取 64 字节认文件头（ID3 / fLaC / OggS / RIFF / ftyp…）：
   认得出 → **可用**；拿到地址但内容不是音频（错误页 / JSON）→ **仅地址**。
   腾讯那个「地址能拿到、内容是错误页」的坑就是这么抓出来的，只判 URL 判不出来
5. 平台之间**串行**，同一平台内最多 3 档里跑 2 个 —— 所有平台共用同一批脚本，
   并发一高容易被限流，整张表会误判成「全都不支持」

**怎么读结果**

- 某平台整行都是「—」：脚本根本没声明这个平台，去「音源：…」下拉里换一个脚本
- 某平台只有 128K 可用，320K / FLAC 失败：这个脚本（或这条线路）只给低档，
  想要无损得换脚本，或者接受「自动」一路降到 128K
- 「仅地址」很多：多半是取链成功但 CDN 要 referer / 防盗链，或者那首歌已下架
- 结果只代表样本，不代表所有歌都能出这一档：用来判断「这个脚本值不值得留」够用，
  不适合当「这首一定能播」的保证

检测跑完会写进状态栏（`音源音质检测完成：9/15 格可用…`），关掉浮层这一轮就作废
（不会再往关掉的表格里写结果），设置面板那一行也会显示上次检测的时间与结论。

## 十二、常见问题

**面板显示「没有可用的音源脚本」**
检查本目录下有没有音源 `.js`，或设置 `lx.scriptDir`；控制台里 `[LX][err]` 会有具体报错。

**取链报「没有脚本声明支持音源 wy」**
音源脚本没加载成功，或没声明该平台。按错误里的「可用平台 / 已加载脚本及状态 / 当前脚本目录」定位；
常见原因是 `lx.moduleDir` / `lx.scriptDir` 还指着旧目录，删掉这两个属性即可。

**取链报 `guard: unknown magic`**
音源脚本做二进制探测时拿到了错误字节（面板已改用 `curl.exe` 探测）。
若仍出现，检查 `C:\Windows\System32\curl.exe` 是否存在或被杀软拦截。

**加载时报 `include failed: Path does not point to a valid file: crypto.js`**
`include()` 的相对路径基准和加载方式有关，`main.js` 会自动按多个目录探测；
放在别处时把属性 `lx.moduleDir` 指过去。

**改了 `main.js` 面板还是旧的**
JSplitter 会缓存脚本，在 Configure 里点一次 Apply，或重开面板。

**搜索框点了打不进字**
先在面板 Configure 里勾上 **Grab focus**（`on_key_down` 需要它才触发）；
中文用右键「输入关键词（中文输入法）…」或 `Ctrl+V` 粘贴。

**中文输入法只能看到提示，打不出汉字**
不是面板的 bug：SMP / JSplitter 没有 IME 控件，画不出候选框。

**搜索 / 歌单 / 评论失败**
平台接口可能临时限流或变更，换平台或稍后重试；QQ 搜索失败会自动走旧版 Web 接口兜底。

**左栏（榜单 / 歌单列表）不见了**
多半是点到了左栏右上角那个箭头，收起来了。再点一次展开（窄边顶部那个朝右的箭头）；
也可以在面板属性里把 `lx.sideCollapsed` 写成 `0`。

**播放卡在「正在缓存」**
下载慢或失败，失败会自动回退成直接播放直链，日志里会写
`[LX][warn] 缓存失败，改为直接播放`。想彻底关掉缓存把 `lx.download` 设 `0`。

---

## 十三、备份

把整个 `<profile>\Lxbox\` 打包备份即可，升级时覆盖回去。
`cache\` 里既放音频（含内嵌封面）也放索引与资料缓存，整个 `cache\` 可以不备份 ——
删掉会自动重下，评论 / 简介会重新取。
